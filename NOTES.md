## Prior art

* ebourg/kotlin-bootstrapping: Kotlin 0.6.786 → 1.0.0 on Debian (Ant, prebuilt IntelliJ SDK jars).
* guix-android (Julien Lepiller): the same in Guix, stuck right after 1.0.0

### JDK (nix/jdk) — in progress
Port of Guix' java-bootstrap.scm: jikes → GNU Classpath 0.93 → JamVM 1.5.1 →

## Status: Kotlin 1.2.31 (Ant era complete)

Built with Ant from source: 1.1.3-dev-1317 .. 1.1.4, 1.1.51, 1.1.60, 1.2.0,
1.2.10, 1.2.21, 1.2.31 (`nix build .#kotlin."1.2.31"`).  Per-version notes:
* 1.1.3+: `build.xml` delegates the runtime to Gradle, so the Ant runtime
  targets of 1.1.2 are spliced back (`patches/own/runtime-targets-*.xml`).
  1.2.x versions: kotlin-test needs `annotations-common` (expect decls) and
  `-Xmulti-platform` (1.2.0); `core/descriptor.loader.java` became
  `core/descriptors.jvm` (1.2.21); builtins also include
  `libraries/stdlib/jvm/runtime` (1.2.31).
* 1.2.10: compiler needs `-jvm-target 1.8` (Java-8 static interface calls).
* 1.2.31 needs IntelliJ SDK 181 (JavaModuleSystem, JvmElementProvider);
  `patches/own/sdk-181.patch` is sdk-173's port, plus lz4-java replaced by
  Snappy in `CompressionUtil`.  `compiler.xml` moved to `compiler/cli/src`.
* JDK 12+: glibc >= 2.42 declares `uabs()` (renamed in hotspot), 14+ needs a
  stub `<sys/sysctl.h>` (jpackage).

## Status: Kotlin 1.2.40 .. 1.2.71 (restored build.xml)

* 1.2.40+: `build.xml` is gone upstream; 1.2.31's is reused (plus new module
  dirs).  1.2.50+: "fresh stdlib" (the new stdlib compiled by the previous
  compiler) as `bootstrap.runtime`, `-Xread-deserialized-contracts
  -Xeffect-system`.
* 1.2.60: stdlib needs `-Xuse-experimental=kotlin.Experimental`; 1.2.70 also
  `kotlin.ExperimentalMultiplatform`, IntelliJ SDK 182, `-Xnew-inference`
  (sources are written for it) with callable references to vararg
  constructors / inline functions rewritten as lambdas (codegen crashes),
  and `kotlin-annotations-jvm` compiled into `lib/`.
* IntelliJ SDK 182/183/191/192/193 (`patches/own/sdk-NNN.patch`): JDOM 2
  fork, ASM 7, lz4 replaced by a small `lz4-compat`, imgscalr, streamex, JNA
  5, commons-compress (+ xz, brotli, zstd stub); SVG/batik, mac UI and form
  instrumentation removed.
* JDK chain reaches 21 (19+: jmod `--date` needs SOURCE_DATE_EPOCH >= 1980).

### 1.3.0 (from 1.2.71)
Upstream built 1.3.0 from 1.3 pre-releases only.  1.2.71 has the 1.3
language features as unstable ones, but its release-coroutines codegen
targets `kotlin.SuccessOrFailure` (renamed to `Result` in 1.3-RC).  So the
fresh stdlib (only compiled against) has `Result` renamed back, and the
compiler built by 1.2.71 must not use coroutines itself: two `sequence {}`
blocks are rewritten, `runBlocking` replaced by a latch.  The stdlib's
1.3-only binaries are "pre-release" for 1.2.71 →
`-Xskip-metadata-version-check`.

## Plan beyond Kotlin 1.1.2-5

* Kotlin's Ant build.xml survives until 1.2.31 (gone in 1.2.40), but from
  1.1.60 on the runtime/stdlib are built by Gradle (`gradle-runtime` target).
  → continue with Ant through 1.1.3/1.1.4/1.1.51 (TarCV's leftover patches),
  then replace the `gradle-runtime` target by a direct kotlinc build of the
  stdlib, up to ~1.2.31.
* After that: write per-version Nix builds that compile the compiler modules
  directly with the previous kotlinc + javac (no Gradle), stepping through
  `build-*-dev-*` tags.  Needs newer IntelliJ SDK modules (173, 181, 183, …),
  which themselves contain Kotlin code from some point on, so the IntelliJ and
  Kotlin chains have to be interleaved.
* Gradle: compile a recent Gradle's subprojects directly (javac/groovyc/
  kotlinc) instead of bootstrapping Gradle-with-Gradle; needs Groovy (Guix
  has a from-source Groovy recipe) and Kotlin ~2.x with scripting/embeddable
  artifacts.

## Kotlin 2.1.0 → 2.4.0 (done)

Chain: 2.0.0 (K1 only) → 2.1.0 (FIR, built by 2.0.0) → 2.1.20 (bridge: first with named
context parameters) → 2.2.0 → 2.3.0 → 2.4.0 (`nix build .#kotlin."2.4.0"`).
Things worth knowing:
* FIR needs `ANT_OPTS=-Xmx14g`; the stdlib/builtins/reflect are compiled from source by K2.
* 2.3 split/merged many modules (psi, cli-common, ...) and 2.4 moved more (core/names,
  core/language.*, cli-jvm, cli-metadata): `relocate-modules*` steps move files back to
  where the inherited patch steps expect them; new module dirs are added in the dir lists.
* The 2.3.0 compiler ignores `-Xopt-in` for some args (use `-opt-in`), and cannot compile
  explicit backing fields on overrides / `return` in expression bodies: patched in 2.4 sources.
* 2.4's JS parser is ANTLR-generated: regenerated with the tunnelvisionlabs ANTLR 4.7.4 chain
  (nix/java/antlr.nix) instead of the committed 4.13.2 output.
* CRI (kotlinx.serialization plugin) is dropped; Ant tasks are gone since 2.3 (kotlin-ant.jar is
  handed down from the bootstrap).
Next: Gradle 9.8.0 (~10.5k Java, 770 Kotlin, 110 Groovy main sources in ~190 modules; see the
8.14.3 survey above) compiled module by module with javac/groovyc/kotlinc.
